# サブエージェントから起動した場合

reviewing-code・reviewing-criticalを、最上位のセッションではなくサブエージェントの中から起動したときに起きること（2026-10-01に観測）と、そのときの進め方。

## 起きること

- **report.mdを書けない**: オーケストレーター（起動したサブエージェント）の`report.md`へのWriteが「Subagents should return findings as text, not write report files.」で拒否される。レビュアーが書く`{レビュアー名}.md`は書ける
- **レビュアーの完了を待てない**: レビュアーの完了通知と最終報告は、オーケストレーターではなく最上位のセッションに届く。オーケストレーターはレビュアーを起動したあと自分のターンを終えて止まり、Phase 4へ進めない

## 進め方

- レビュアーを起動したら、起動した数と出力先の絶対パスを最終報告にして止まる。呼び出し元には、レビュアーの完了通知がそちらに届くことを伝え、全員の`.md`がそろったら再開を送ってもらう
- 再開を受けたら、出力先の`.md`を読んでPhase 4を進める
- `report.md`は書かず、全文を最終報告の本文に入れて返す。保存は呼び出し元が行う
