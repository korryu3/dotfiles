# save — 会話をjournalに保存する

ここまでの会話からVoice（本人の発言原文）を拾い、1回で保存する。

## 書式（journal互換）

`~/.claude/context/self/journal/YYYY-MM-DD.md`に、1回の対話=1エントリで追記する:

    ---
    timestamp: HH:MM
    context: <プロジェクト名/話題。不明なら省略>
    ---

    ### Voice

    <本人の発言を原文のまま、時系列で。一切改変しない>

    ### Mirror（任意・省略が正規）

    <出所つきの読みと本人の反応。書くことがなければセクションごと省略>

## 手順と注意

1. `date '+%Y-%m-%d %H:%M'`で日時を取得する
2. 追記はRead→全文取得→全文Write。**Editは使わない。Writeは上書きなので、断片だけを渡すと既存の記録が消える**（ファイルがなければ新規作成）
3. `~/.claude/context/self/index.md`に1行追記: `YYYY-MM-DD | journal | <本人の言葉からのタイトル。要約しない> | ●/○`（●=往復が生じた濃い対話／○=軽い受領。迷ったら○）
4. コンテキスト圧縮等で原文が確実でない部分は、要約であることを明記する（原文を装わない）
5. `~/.claude/context/self/`配下はローカル専用。commit・PR・外部出力への引用をしない
6. 保存を終えたら/talkの対話方針は解除し、通常の振る舞いに戻る
