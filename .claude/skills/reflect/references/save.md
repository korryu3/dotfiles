# save — 振り返りを保存する

ここまでの対話から、reflectエントリを1回で保存する。

## 書式（対象日ごと）

`~/.claude/context/self/reflect/<対象日>.md`:

    # <本人の一言（原文のまま）。出なかった日は無題でよい>

    - わかったこと: <本人の言葉ベースで。なければ省略>
    - まだわからないこと: <なければ省略>
    - 対話の要点: <出所つきの読みと本人の反応を2-3行まで。任意>
    - 種: <種床に播かれた場合のみ、本人の文言>

## 手順と注意

1. 追記・新規作成はRead→全文取得→全文Write。**Editは使わない。Writeは上書きなので、断片だけを渡すと既存の記録が消える**
2. `~/.claude/context/self/index.md`に1行追記: `YYYY-MM-DD | reflect | <本人の一言。要約・言い換えをしない> | ●/○`（●=往復が生じた濃い対話／○=軽い閉じ。迷ったら○）
3. `seeds.md`に書くのは本人が文言を書いたときだけ・本人の文言のみ（Read→全文Write）
4. コンテキスト圧縮等で原文が確実でない部分は、要約であることを明記する（原文を装わない）
5. `~/.claude/context/self/`配下はローカル専用。commit・PR・外部出力への引用をしない
6. 保存を終えたら/reflectの対話方針は解除し、通常の振る舞いに戻る
